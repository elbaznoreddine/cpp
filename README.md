# 🚀 cpp

A compact C++ playground built for solving problems, sharpening logic, and exploring the fundamentals of modern C++.

This project is all about turning abstract ideas into working code: classes, memory management, algorithms, and clean problem-solving habits. It is the kind of repository where curiosity meets implementation.

## ✨ What is inside

- Core C++ practice and experimentation
- Data structures and algorithmic thinking
- Reusable patterns and clean code habits
- Small but meaningful coding challenges

## 🛠️ Build

```bash
make
```

Then run the generated binary:

```bash
./<program_name>
```

## 🎯 Goal

To make C++ feel less like syntax and more like a superpower.

> Built with patience, debugging, and just enough coffee.
